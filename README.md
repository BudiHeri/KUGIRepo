# KUGIRepo
repositori skema aplikasi dan katalog unsur geografis indonesia (KUGI)

repositori ini dibuat untuk menyediakan tipe data dan kelas-kelas dasar yang bisa digunakan pemangku kepentingan dalam menyusun skema aplikasi standar data geospasial.
tipe data dan kelas-kelas dasar disusun berdasarkan ISO 19103 dan ISO 19109.

segala pertanyaan mengenai konten repositori bisa diajukan ke Direktorat Standar dan Teknologi Informasi Geospasial, Badan Informasi Geospasial.
